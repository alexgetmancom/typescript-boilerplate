# Security Policy

## Supported versions

The `main` branch is the supported version of this template.

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Use GitHub's private vulnerability reporting for this repository when available. If it is not enabled, contact the repository owner through GitHub with the repository name, affected commit or version, impact, reproduction steps, and any suggested mitigation.

Please allow reasonable time for investigation and coordinated disclosure before publishing details.
